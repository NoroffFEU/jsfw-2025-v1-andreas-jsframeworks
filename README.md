# Online Shop – Noroff JS Frameworks Project

## Getting Started

Follow these steps to run the project locally:

```bash
# 1. Clone the repository
git clone https://github.com/Andreasvds10/jsfw-2025-v1-andreas-jsframeworks.git

# 2. Navigate into the project folder
cd jsfw-2025-v1-andreas-jsframeworks/online-shop

# 3. Install dependencies
npm install

# 4. Start the development server
npm start
